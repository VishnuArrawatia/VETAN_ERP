1. How to Open VETAN ERP

🌐 ERP Link (Bookmark this!)

https://vetan-svn.vercel.app

On Computer (Windows/Mac):

Open Google Chrome or Microsoft Edge browser
In the address bar, type: https://vetan-svn.vercel.app
Press Enter — The login page will open
Bookmark it: Press Ctrl + D to save as bookmark for quick access

On Phone (Android/iPhone):

Open Chrome (Android) or Safari (iPhone)
Type: https://vetan-svn.vercel.app
Tap ⋮ (3 dots) → "Add to Home Screen" → "Add"
A VETAN ERP app icon will appear on your home screen
💡 Tip: Phone pe install karne ke baad browser bar nahi dikhega — full screen app jaisa lagega!

"Employee Master" page pe + Add Employee button pe click karo
Form khulega — saari details fill karo:
  • Employee ID — Unique ID (e.g., SK1ST0050)
  • Name — Full name as per records
  • Company — Select SVN-1 / SVN-II / Sakar-I / Sakar-III

  • Designation — Worker / Staff / Officer
  • Date of Joining — Start date
  • Phone — Mobile number

17. Troubleshooting — Common Problems & Solutions

ProblemSolution
ERP khul nahi raha / "Site can't be reached"
  1. Internet check karo — WiFi ya Data ON hai?
  2. Link check karo: https://vetan-svn.vercel.app
  3. Browser restart karo (Chrome close → wapas kholo)
  4. Phone pe: Settings → Apps → Chrome → Clear Cache
"Authentication service unavailable"
  1. Internet connection slow hai — thoda wait karo
  2. Page reload karo (F5 ya pull-to-refresh)
  3. Agar 1-2 minute mein nahi hota — Vishnu ko batao
"Employee not found"
  1. Employee ID sahi hai? (Check: SV1ST0046, SK1ST0033)
  2. Capital/Lower case matter nahi karta
  3. Spaces check karo start/end mein
"Incorrect Password"
  1. SVN employees: Phone ke last 4 digit + Birth Year (e.g., 99111995)
  2. Sakar employees: 00001995
  3. Agar password change kiya hai toh naya password use karo
  4. Reset ke liye Vishnu se contact karo
Data dikha fir gayab ho gaya
  1. Data Supabase cloud pe save hota hai — safe hai
  2. Page reload karo — wapas aa jayega
  3. Internet check karo
Attendance save nahi ho raha
  1. Saari required fields fill kiye?
  2. Month/Year sahi select kiya?
  3. Page reload karo aur dubara try karo
Payroll calculation galat aa raha hai
  1. Attendance sahi mark ki hai? (Present days check karo)
  2. Salary structure sahi hai? (Employee Master mein check karo)
  3. Company sahi select kiya?
"Failed to fetch"
  1. Internet connection check karo
  2. VPN ya proxy use kar rahe ho? OFF karo
  3. Browser ka cache clear karo
  4. Dusra browser try karo (Chrome → Edge)
📞 Kisi bhi serious problem ke liye contact karo:
Vishnu Arrawatia — Super Admin
